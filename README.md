# Ingeniería de Software I

Material de estudio y prácticas de Ingeniería de Software I (Facultad de Informática, UNLP), cursada 2024.

## Estructura

- `teoria/`: diapositivas de las clases teóricas.
- `practica/practica1` a `practica5/`: enunciados y explicaciones de cada práctica.

## Temas

- Técnicas de elicitación de requerimientos
- Historias de usuario
- Casos de uso
- Diagramas de transición de estados
- Redes de Petri
- Análisis estructurado y tablas de decisión

---

Las resoluciones son propias y pueden tener errores. El material de cátedra (diapositivas, enunciados y parciales) pertenece a sus docentes y está incluido solo como referencia de estudio.
